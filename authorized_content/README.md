# 授权内容目录

请将你拥有合法授权的本地内容文件放入此目录。

## 支持的导入类型

### 1. 剧情大纲 (story-outline)
描述章节结构、剧情走向、关键事件。

### 2. 术语设定 (terms)
世界观术语、系统名称、专有名词。

### 3. 称号 (titles)
称号名称、描述、效果、稀有度。

### 4. 角色信息 (characters)
角色名称、背景、能力、关系。

## 文件格式

支持 JSON、TXT、Markdown。

### JSON 格式示例

```json
{
  "type": "story-outline",
  "data": {
    "chapters": [...],
    "choices": [...]
  }
}
```

## 导入流程

1. 将文件放入此目录。
2. 在游戏中打开「授权导入」页面。
3. 填写来源信息并上传/指定文件。
4. 内容进入 draft 状态。
5. 在草稿管理中审核内容。
6. 确认后发布为正式内容。

## 警告

- 请确保你拥有导入内容的合法授权。
- 导入内容不会自动覆盖已有正式数据。
- 授权文件不会被提交到版本控制。
