# 授权说明

## 授权状态

本项目使用的内容授权状态由此文件记录。

---

## 授权文件位置

请将授权相关文件放入以下目录：

```
/authorized_content/
```

支持的格式：JSON、TXT、Markdown

---

## 授权内容使用方式

1. 将授权内容文件放入 `/authorized_content/` 目录。
2. 使用游戏内的「授权导入」页面或 API 导入内容。
3. 导入的内容默认进入 **草稿（draft）** 状态。
4. 草稿需要手动审核并发布后，才会转为正式游戏内容。
5. 已发布的正式内容不会被自动覆盖。

---

## 责任声明

- 请确保你拥有导入内容的合法授权。
- 本项目不会联网抓取任何受版权保护的内容。
- 导入功能仅处理你本地提供的文件。
- 授权文件不会被提交到版本控制系统（已在 .gitignore 中排除）。

---

## 导入 API

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/import/story-outline` | 导入剧情大纲 |
| POST | `/api/import/terms` | 导入术语/设定 |
| POST | `/api/import/titles` | 导入称号 |
| POST | `/api/import/characters` | 导入角色信息 |
