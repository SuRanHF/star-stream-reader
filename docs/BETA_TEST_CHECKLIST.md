## 告知群友

发送给群友的信息应包含：

1. **访问地址**：`https://你的域名`
2. **这是测试服**：数据可能在更新时重置，不代表最终品质
3. **如何反馈**：点击右下角"反馈"按钮，或直接告诉开发者
4. **后台地址**：不要发！`/admin` 仅供开发者使用

## 日常维护

### 数据备份
```bash
# 从服务器下载数据库
scp user@host:~/data/game.db ./backups/game-$(date +%Y%m%d).db
```

### 查看反馈
1. 访问 `/admin` → 反馈管理
2. 或直接查看 `data/feedback.json`

### 重置测试数据
1. 停止服务器
2. 删除 `data/game.db`
3. 重新启动服务器（自动重建数据库和 seed 数据）

### 创建 admin 账号
```sql
-- 在数据库中将已有用户设为 admin
UPDATE users SET role = 'admin' WHERE username = '你的用户名';
```
